### 2. Baixando os arquivos

**Opção A — Clonar o repositório (recomendado):**
```bash
git clone https://github.com/seu-usuario/workshop-wordpress-etec.git
```

**Opção B — Download manual:**
1. Clique no botão verde **"Code"** no topo desta página
2. Selecione **"Download ZIP"**
3. Extraia o arquivo na sua máquina

---

### 3. Instalando o tema no WordPress

1. Abra a pasta `meu-tema/` que você baixou
2. Comprima ela em um arquivo `.zip`
3. No painel do WordPress, vá em **Aparência → Temas → Adicionar novo**
4. Clique em **"Fazer upload do tema"**
5. Selecione o arquivo `.zip` e clique em **"Instalar agora"**
6. Clique em **"Ativar"**
7. Acesse seu site e veja o tema funcionando! 🎉

## 📚 Conteúdo do workshop

### Parte 1 — Conhecendo o WordPress
- O que é WordPress e por que o mercado usa
- Diferença entre WordPress.com e WordPress.org
- Tour pelo painel de administração
- O que são temas e plugins
- Temas prontos, Elementor e construtores visuais

### Parte 2 — Criando o tema com código
- Estrutura de arquivos de um tema
- `style.css` — como o WordPress identifica o tema
- `functions.php` — registrando scripts e ativando funcionalidades
- `header.php` e `footer.php` — componentes reutilizáveis
- `front-page.php` e `single.php` — templates de página
- **The Loop** — como o WordPress exibe conteúdo
- Upload e ativação do tema
